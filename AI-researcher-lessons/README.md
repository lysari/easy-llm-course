# AI Researcher — From Beginner to Researcher

This curriculum teaches you how to **do AI research**, not just build models.
It is the companion track to [lessons/](../lessons/) (LLM from scratch). That track teaches you
how models work. This track teaches you how researchers *think*: the math they lean on,
how they read and reproduce papers, how they design experiments, and how they write and
publish their own work.

**Who this is for:** a beginner who can program (TypeScript) and is willing to build
everything from scratch. No prior ML or university math required — every math lesson
starts from zero.

**How to use it:** go in order. Each lesson has a `lesson.md` (the concept) and, where it
makes sense, an `index.ts` (run it with `npx ts-node index.ts` or `bun run index.ts`).
Later lessons have `exercise.md` files — real research practice, not toy quizzes.

---

## The Path

```
Phase A: Math Foundations      → the language research is written in
Phase B: Deep Learning Science → why training works (not just how)
Phase C: Papers                → read, reproduce, and critique real research
Phase D: Experiments           → the craft of producing evidence
Phase E: Frontiers             → the open problems researchers work on today
Phase F: Becoming a Researcher → find a question, do the work, write it up
```

## How this connects to the from-scratch track

| When you reach… | …do these from-scratch lessons |
|---|---|
| After Lesson 02 (Calculus) | [lessons 00–07](../lessons/) — models, loss, gradient descent, backprop |
| After Lesson 05 (Numerical) | [lessons 08–14](../lessons/) — matrices → tiny GPT |
| After Lesson 09 (Scale) | [lessons 15–21](../lessons/) — FFN, Adam, GPT-2, KV cache |
| After Lesson 15 (Reproduce) | [lessons 22–25](../lessons/) — scaling laws, sampling, RoPE |
| During Phase E | [lessons 26–30](../lessons/) — finetuning, RLHF, MoE, GPT-4 capstone |

By the end of both tracks you will have: built a GPT from scratch, reproduced a real
paper, run statistically sound experiments, and completed one original mini research
project written up as a paper. That is the researcher's starter kit.
